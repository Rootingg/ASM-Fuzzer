# Code de conduite

## Engagement

Ce dépôt est un projet d'apprentissage et un outil de recherche en sécurité. Chacun participe de façon respectueuse, que ce soit dans les issues, les reviews ou les discussions.

## Comportement attendu

- Formuler des critiques sur le code et les choix techniques.
- Documenter les reproductions sans exposer de données sensibles.
- Accepter qu'une pull request puisse attendre un check CI ou une clarification.

## Comportement inacceptable

- Harcèlement, insultes, ou attaques personnelles.
- Publication d'exploits, de secrets ou de données personnelles.
- Demande d'aide pour attaquer un système sans autorisation.

## Application

Écrire à [@Rootingg](https://github.com/Rootingg) ou ouvrir un avis de sécurité privé pour un signalement qui ne doit pas être public. Une contribution qui enfreint ce code peut être fermée ou retirée.
